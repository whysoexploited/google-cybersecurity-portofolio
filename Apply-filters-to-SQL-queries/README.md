
# Apply Filters to SQL Queries

## Overview

This project demonstrates the use of SQL filtering techniques to support cybersecurity investigations and system administration tasks. Working with employee and login activity datasets, I used SQL queries to identify suspicious login attempts, investigate potential security incidents, and retrieve information about employee systems requiring security updates.

## Skills Demonstrated

- SQL querying and data retrieval
- Data filtering with WHERE clauses
- Using AND, OR, and NOT operators
- Pattern matching with LIKE and wildcards (%)
- Filtering dates and times
- Security event investigation
- Log analysis and employee asset management

## Project Objectives

The queries in this project were designed to:

- Identify failed login attempts outside normal business hours
- Investigate login activity during specific dates related to a security event
- Review login attempts originating outside designated locations
- Locate employee devices requiring security updates
- Filter and analyze organizational data to support security operations

## Technologies Used

- SQL
- Relational Databases

## Outcome

This project highlights how SQL can be applied in cybersecurity to efficiently search, filter, and analyze large datasets. These skills are commonly used by security analysts when investigating incidents, monitoring user activity, and supporting organizational security initiatives.
