# Network Traffic Analysis Incident Report

## Overview
This project documents the analysis of a network connectivity issue affecting the website `yummyrecipesforme.com`. Using packet capture data and network traffic analysis, I investigated DNS and ICMP traffic to determine the cause of the service disruption.

## Key Findings
- Analyzed network traffic using `tcpdump`.
- Identified ICMP error messages indicating that UDP port 53 was unreachable.
- Determined that port 53 is commonly used by DNS services.
- Investigated potential causes of the DNS service outage.
- Considered possible security-related causes, including service disruption and Denial-of-Service (DoS) activity.
