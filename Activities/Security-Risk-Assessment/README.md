# Security Risk Assessment

## Overview
This project evaluates security risks within an organization and provides recommendations to strengthen security controls and reduce potential threats to company assets, systems, and data.

## Security Recommendations

### 1. Multi-Factor Authentication (MFA)
- Implement MFA for user accounts.
- Reduce the risk of unauthorized access caused by shared or compromised passwords.
- Improve account security through an additional authentication factor.

### 2. Password Policies
- Enforce strong password requirements.
- Eliminate default or weak passwords.
- Improve resistance against password guessing and brute-force attacks.

### 3. Firewall and Port Management
- Configure firewall rules to allow only necessary traffic.
- Apply port filtering to reduce exposure to unnecessary services.
- Perform regular firewall reviews and maintenance to minimize the attack surface.

## Project Outcome
The proposed controls improve the organization's security posture by strengthening authentication mechanisms, enforcing secure password practices, and limiting network exposure through firewall and port management. These measures help reduce the likelihood and impact of unauthorized access and cyberattacks.
